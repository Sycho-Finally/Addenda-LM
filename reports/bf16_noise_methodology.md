# bf16 执行噪声与漂移测量的三分解协议

技术笔记 ｜ 2026-10-02 ｜ Addenda-LM 项目 ｜ 复现脚本: `experiments/pegp_decomp_test.py`

---

## 问题

在冻结基座上挂附加模块（adapter/分支/记忆层）的实验里，"旧任务漂移"的标准测法是：
`漂移 = metric(模块激活) − metric(模块关闭)`。

我们在这个测法下观察到一个反常现象：一个**数学上恒等于不存在**的模块（零初始化输出），
只要它的计算被接进前向图跑一遍，测得的"漂移"就显著非零——在三分解实验中，
该纯执行差异达 mean −2.17 / max 3.48（20 条旧任务 gold logprob）。

## 根因

三个因素叠加：

1. **bf16 数值精度**：残差流存在大激活坐标（本模型实测 ~7000，bf16 在该量级的 ULP=32）。
   任何 ±ULP 量级的数值扰动都会被大坐标放大成可观测的输出差异。
2. **执行上下文改变 cuBLAS 行为**：模块自身的矩阵乘（哪怕输出为零）会改变 CUDA 工作区/
   算法选择状态，使随后同形状的基座矩阵乘落在不同的 reduction 路径上 → 结果在 ULP 级别不同。
3. **大激活坐标的杠杆效应**：ULP=32 的坐标差通过后续层的 LayerNorm/Attention 被整形，
   在 gold logprob 上表现为 ±O(1)~O(10) 的漂移。

即：**测得的漂移 = 模块语义效应 + 执行噪声**， naive 测法把两者混在一起。

## 三分解协议

同一训练后的模型，在旧任务测试集上测三种模式：

| 模式 | 含义 | 作用 |
|---|---|---|
| `off` | 模块完全不执行（钩子直通） | 基准 |
| `zero` | 模块执行但权重零初始化（数学恒等） | 与 `off` 之差 = **纯执行噪声** |
| `trained` | 模块执行且已训练 | 与 `zero` 之差 = **真实语义效应** |

```
执行噪声   = metric(zero)    − metric(off)
语义效应   = metric(trained) − metric(zero)
表观漂移   = metric(trained) − metric(off)   ← naive 测法报的数
```

## 实测（Qwen3-4B-Instruct-2507, 6GB, 单卡）

- 执行噪声：mean −2.17，max |d| 3.48（数学恒等模块！）
- 语义效应：mean +0.53，max |d| 1.02
- 噪声占表观漂移的 **80.2%**

推论：

1. 任何"全局激活漂移"的公开数字若未做三分解，应默认含执行噪声成分。
2. 模块"越强漂移越大"的结论需重新审视：更强的模块矩阵乘更多，噪声占比也更高。
3. 结构性隔离（路由：未路由输入连模块矩阵乘都不执行）是唯一逐位精确的方案；
   统计正则只能压语义部分，压不掉执行噪声。

## 适用范围与限制

- 结论在 bf16 + 大激活坐标架构（Qwen3 系实测）上成立；fp16/fp32 主干、无大激活的模型噪声水平未测。
- `zero` 模式的数学恒等性依赖零初始化输出设计（w_out 零初始化）。
- 语义效应的测量仍受执行噪声污染（两次前向的上下文不同），其置信界应把噪声幅度计入。
- 本笔记只报告单机单卡观察；多卡/不同 CUDA 版本的噪声特性未测。

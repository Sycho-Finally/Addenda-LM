## 1. Memory as a Markov Matrix（ICML 2026, arXiv:2605.04308）★ 与本框架理论关系最近

### 机制
- 把自回归生成建模为 token 上的一阶马尔可夫过程（上下文 K 的模型 = K 阶链，经 NULL 填充增广状态空间），模型记忆 = 转移矩阵。
- **新知识 = 状态空间扩展**：新 token 集合 U 并入词表，旧 token 间转移保持原值 → 查询旧 token 时行为与原模型**完全一致（零遗忘的形式化保证，由构造成立）**。
- **Token-to-dictionary 映射**：新 token u 的转移行为 = 原嵌入字典上的稀疏组合 f(Eᵀα⁽ᵘ⁾)，‖α‖₀ ≤ s（至多 s 个现有 token 的结构化混合）。
- **Embedding-Tuning（ET）**：只训练新 token 的嵌入行（Llama-3.2-3B 上仅 3,072 参数），其余全部冻结。新 token 的经验转移分布经 KL 投影拟合进嵌入。
- **样本复杂度**（定理 1/2）：一对一映射下，识别 v*(u) 需 N ≥ O(m·γ⁻²·log(mT/δ))（γ = token 间转移分布的最小 KL 分离度）；稀疏组合下每新 token O(s·log²c)——**与词表大小 T 和模型维度 d 无关**，由语义粒度 s 决定。

### 实验
- 算术算符 token（Llama-3.2-3B）：⟨spec⟩ 学乘法，N≈500 即强性能；FFT 把加法 100%→0%（且在加法 prompt 上输出乘法结果 76.2%），**ET 保持加法 100%、乘法 81.4% 超过基线集成的 73.2%**（支持稀疏组合假设）。
- 合成词表扩展（7 个模型 1B-8B）：ET 遗忘全部 0.00，FFT 最高 +11.59，LoRA 最高 +8.80。
- 跨语言（Qwen2.5-3B）：ET 目标语损失最低、英语遗忘 -0.08~0.00（轻微负遗忘，机理未明——与我们观察到的"向上漂移"同类现象）。

### 与 Addenda-LM 的关系：两种正交的模块形态
- **他们的 ET = 新状态扩展**：新知识包装成新 token（新状态），旧转移由构造不变——零遗忘免费。适用前提：知识可以打包成"新入口触发既有能力"（他们的乘法 token 触发的是基座已会的乘法电路）。
- **我们的残差分支 = 转移重写**：修改**既有 token** 的转移行为（基座不知道的密码映射/事实）——不存在"新状态"可用，必须改写旧状态的计算，因此需要门/锚/路由兜底。
- **关键判据（可检验）**：ET 只能"路由到既有能力"，存不了基座不知道的任意映射。我们的密码任务（基座完全不知道的密钥）正是 ET 的反例场景——**提案 R5：新 token + ET 形态跑密码任务，预期失败，以此实证两种形态的能力边界**。
- 我们的密码相变曲线（64→256 样本）与他们的定理呼应：样本复杂度由映射的语义粒度决定，与我们观察到的"每数字需几十次曝光"同量级现象。

### 局限（他们自述）
新 token 均匀出现假设；无 V→U / U→U 转移的简化；模型表达力假设；负遗忘机理未明。

## 2. Engram Adapter（EMNLP 2026 Findings, arXiv:2608.29327）★ 同基座同构

### 机制
- 预训练时的条件记忆改造为事后适配器：**多通道局部 n-gram 匹配 + 占用追踪**作为选择性先验（决定哪些输入倾向注入），**学习型标量门**抑制不相关的 OOD 检索。
- OOD 时激活非零，但门+投影衰减把残差压到**隐状态范数的 ~0.08%** → 小 KL 漂移、精度可忽略变化。

### 实验
- Qwen3-4B / Qwen3-8B；适应任务 AG-News、MedMCQA；OOD 覆盖推理/翻译/代码/法律。
- 域内提升的同时 OOD 保持 99.4%-100.1%；LegalBench 上略超冻结基座；对照的 always-on 基线急剧退化。

### 与 Addenda-LM 的关系
- 同基座（Qwen3-4B）、同机制家族（词法匹配→门→残差注入）。
- **差异 1（隔离方式）**：他们"衰减到 0.08%"（统计近零，仍有执行），我们"路由不执行"（结构性 bit-exact）。
- **差异 2（真伪层缺失）**：他们的门是**域相关性门**（该不该注入），没有**真伪核证**（该不该信）——我们的门+证溯层是可叠加增量。
- 差异 3：他们针对域适应（AG-News/MedMCQA 大类任务），我们针对事实/技能注入（细粒度）。
- **R2 嫁接实验的落点**：Engram 式条件适配器 + 我们的真伪门 = "相关性 × 可信度"双门。

## 3. Brainstacks（arXiv:2604.01152）

- 冻结 MoE-LoRA 栈（7 个投影矩阵，QLoRA 4bit）+ 残差提升（内环）+ 课程式域堆叠（外环）+ 随机 SVD 零空间投影 + outcome-based sigmoid meta-router。
- 核心发现：**域栈编码的是可迁移认知原语（指令遵循/数值推理/程序逻辑），不是域知识**——医疗 prompt 97% 路由到 chat+math 栈（栈内零医疗数据）。
- 关系：跨层+零空间+路由的组合覆盖比我们完整（2 个模型、RL 兼容实验）；"路由发现认知原语"的发现与我们的"技能 vs 知识"边界互为印证——他们的栈学的是程序性原语，恰好对应我们"技能模块需要跨层×数据量"的结论。

## 汇总：Addenda-LM 的生态位（2026-10-02 版）

1. **组件级**：全部有先行者，无首创声明空间。
2. **组合级**：无五件套闭环；最接近的 Engram 缺真伪层，Markov Matrix 缺"既有状态重写"。
3. **独立增量**（守住并写透）：真伪门+证溯进闭环；bf16 执行噪声三分解；记忆/程序边界相变曲线；消费级硬件全链路复现。
4. **新增实验提案**：R5 新 token ET 形态 vs 残差分支形态的能力边界对照（预期 ET 学不会任意新映射——实证两种形态的正交性）。

## 5. R5 实验结果（2026-10-02）：两种形态的正交性实证确认

复现脚本 `experiments/r5_et_form_test.py` ｜ 结果 `r5_et_form_result.json`

| 子实验 | 训练 | 结果 | 预期 |
|---|---|---|---|
| ET-cipher n64（仅新嵌入行 2560 参数） | 800 步 | loss 卡 2.31≈ln(10)（均匀瞎猜），seen/unseen 0.000 | 失败 ✓ |
| ET-cipher n500 | 800 步 | loss 2.1-2.45，0.000 | 数据量救不了 ✓ |
| ET-arith n500（正例控制：a⟨crypt⟩b=a×b） | 800 步 | **unseen 命中 0.860** | 成功 ✓ |
| TASK_A 漂移 | — | **-0.0000（逐位精确为零）** | 零遗忘由构造 ✓ |

**结论**：ET（新状态扩展）能路由到基座既有能力（乘法 ✓）但无法编码基座不知道的任意映射（密钥 ✗，数据量无关）；残差分支（状态重写）相反。**两种形态正交、互补、不互替**——模块形态选择的第一层决策树：新知识若能嫁接到既有能力 → ET（2560 参数、零遗忘免费）；基座无底层能力 → 跨层残差分支（贵，需路由隔离）。

**诚实边界**：ET 正例 0.860 未到 100%（ET 的上限受基座乘法能力与路由效率限制）；密钥任务若换设计（如把密钥表作为上下文给 ET 触发查询）可能有不同结果——未测。

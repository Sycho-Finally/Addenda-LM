## 一、我们做了什么（10 组实验的完整弧线）

起点是 master 的「新华字典理论 / 模块图谱型持续学习架构」：冻结基座 + 概念模块 + 连线机制 + 物化闸门。
本报告把这套设计从概念推到了有数字的实验结论。

### 1. 地基：架构是稳定容器
- **4B 实机走向测试**：训练过 vs 随机初始化（同架构），残差流范数轨迹皮尔逊相关 **0.814**，注意力熵为平线+恒定偏移。
- 结论：架构层走向由架构决定，训练只改幅度与离群结构（L7 出现巨大激活跳变 116→7008，平台值全是 bf16 ULP=32 的倍数）。

### 2. 不遗忘：参数级 → 行为级
- **additive 分支实验**：冻结主干，挂 1.3M 参数残差分支（末层零初始化），任务 B（16 条编造事实）只训分支：**0%→100%**；任务 A（20 常识题）：0/20 退化；主干权重 SHA256 前后不变。
- **但行为漂移真实存在**：换真事实数据后 A 漂移 -7.455（14/20 退化）——漂移根源是格式捷径 + 流形外无控外推，不是假数据。"参数不动"≠"行为不动"。

### 3. 门：内容熟化
- **投毒对照**：分支学假话与学真话**一样快**（都是 0→100%）——模型不辨真伪，判定必须在权重之外。
- **规则门自动化**（curator.py，R1 确定性校验 / R2 佐证计分 / R3 准入线 / R4 冲突裁决）：17 条真实网络声明（含 4 组真实冲突 + 投毒）全部正确裁决，与人工核证一致；端到端（raw → 门 → 锚定训练 → 学新不忘旧）无人工贯通。
- **replay 锚**（行为熟化）：KL 锚定把 A 漂移从 -7.455 压到 +0.212（35 倍），几乎无学习代价。

### 4. 路由：结构性隔离
- 双模块（网事实域 + 合成代号域）+ 词法检索路由（bigram Jaccard，阈值 0.25）：路由决策零错误，B1/B2 均 1.00，**任务 A 漂移逐位为零（bit-exact）**；对照同一模块强制全局激活：-13.8，16/20 退化。
- 边界案例：阈值 0.2 时"只用…回答"与代号域模板恰好 0.20 误路由——**路由阈值是回归套件的一部分**。

### 5. 技能边界：记忆 vs 程序（本日最重要的发现）
- **顶层分支**：事实注入 0→100%；**程序注入（随机密码编码，密钥不在 prompt、预训练不可能知道）失败**——seen 0.812 / unseen 精确 0.000，MEMORIZATION-ONLY。
- **中层插入（L18/36）**：修复记忆（seen 1.000），泛化仍 0.000——插入深度不是解。
- **跨层联合分支（6/12/18/24/30 五支，6.5M）× 数据量**：

| 训练样本 | unseen exact | unseen 逐位（随机=0.10） |
|---|---|---|
| 16 | 0.000 | 0.122（≈随机） |
| 64 | 0.375 | 0.722 |
| 128 | 0.938 | 0.865 |
| **256** | **1.000** | **0.973** |

- 相变在 64→128 之间；seen≈unseen 是"学会密钥"的签名。**修正结论：程序可注入，条件 = 跨层组合 × 足量样本多样性；16 条是记忆捷径陷阱。**

### 6. 测量方法论：bf16 执行噪声（意外发现）
- 全局激活的 A 漂移随模块能力增长（+2.4→+6.0），引发"全局激活优化"检索 → 命中 PEGP 并实现（零空间投影，锚输出压到 1e-6）。
- 锚输出≈0 但 A 漂移仍 +5.3 → 三分解实验（off / 挂零初始化分支 / 挂训练后分支）：
  - **执行噪声（数学恒等的模块！）= -2.17，占 80.2%**——分支矩阵乘改变 cuBLAS 上下文，大激活坐标（~7000，ULP=32）产生 ±ULP 噪声；
  - 真实语义效应仅 +0.53（正向格式迁移）。
- **结论：全局激活测量必须三分解，否则测的是噪声；路由（不执行分支矩阵乘）是唯一 bit-exact 隔离。**

## 二、有没有优化空间（有，按杠杆排序）

1. **模块容量形态升级为 Product-Key Memory**：Meta「Memory Layers at Scale」（arXiv 2412.09764）把 PKM 扩到 128B 记忆参数，事实 QA 提升超 100%，匹配算力下胜过 MoE，最优=3 个共享记忆层。我们的分支是稠密 MLP 朴素版——**换 PKM 查找即获得"每模块大容量、零 FLOPs 增长"**，直接对应"每概念一模块"的设计。
2. **数据效率：amortization 取代梯度训练**：MAC 框架用元训练的编码器把文档**一次前向**压缩成 modulation 存入记忆库，免去逐样本梯度。我们的技能模块要 64 样本才诱导电路——MAC 路线把知识注入成本从"64 样本×800 步"降到"1 篇文档×1 次前向"。两者互补：MAC=知识调制，跨层分支=程序电路。
3. **模块间正交**：目前只做了"分支 vs 旧世界锚"；多模块共存应上 **O-LoRA 式跨模块正交**（||B_iᵀB_j||²）或 PEGP 全投影，防模块间互相放大。
4. **路由器升级**：词法 Jaccard → 学习型路由（任务关系矩阵 + graph 先验 + sigmoid 门控）或直接用 PKM product keys 做路由器——**存储与路由统一**。
5. **噪声地板工程**：注入层局部 fp32 残差 / 三分解作为标准测量流程 / 回归套件阈值按噪声地板校准。
6. **grokking 杠杆**：n128 出现晚期 loss 尖峰（0.009→0.245），weight decay + 延长训练可能让 64 样本也泛化。
7. **未测**：多技能并存干扰、技能+路由+回归整合、检索端自动化（真实爬取）。

## 三、类似 / 相关 / 基本一致的项目

### 基本一致（架构原则相同）
| 项目 | 相同点 | 差异点 |
|---|---|---|
| **Macaron-V1**（arXiv 2608.09819，2026-08，开源） | 冻结 744B 基座 + 4 个 1B LoRA 专家按轮路由（MoL Proxy），明示"base 不被改写、新能力=注册新 adapter" | 只做事实域路由，无内容门/投毒防御/漂移测量；专家是全量 LoRA 非轻分支 |
| **MAC**（Memory of Amortized Contexts，开源） | 冻结基座 + 记忆库 + 免梯度在线适应；1400 文档后保持 96%（对照微调 ~70%） | 存 modulation（软提示）而非权重分支；无真伪门；需元训练 amortization 网络 |
| **Memory Layers at Scale**（Meta FAIR，开源） | "专用稀疏容量存储关联知识"，PKM 与我们的模块形态同源 | 用于预训练（从头训），非冻结基座上的后置注入；无门/路由/持续学习闭环 |

### 相关（单组件重叠）
- **O-LoRA**（EMNLP 2023）/ **PEGP**（2405.13383）/ **GPM**（ICLR 2021）/ **DMNSP**（ICCV 2025）：正交/零空间防遗忘——对应我们的锚与投影，PEGP 已被我们实现并暴露 bf16 噪声问题。
- **MixLoRA / Multi-LoRA / AdapterFusion / MoA**：多 adapter + 路由机制分类学——对应路由组件。
- **DKVB（离散键值包）、Progressive Prompts、SAPT、L2R、SwitchCIT**：参数隔离式持续学习家族。
- **L2R**（PEFT 模块 + memory-based router）：与"路由 + 模块注册"几乎同构，但无门与测量方法论。

### 差异化定位（我们做了、检索未见的）
1. **全链路闭环**：门 → 锚 → 路由 → 技能边界 → 测量方法论，在同一个本地 4B 上互相咬合验证（多数项目只验证单组件）。
2. **投毒防御进架构**：门在权重之外、模块可摘除——检索到的持续学习项目均不含真伪判定层。
3. **bf16 执行噪声的三分解测量**：证明全局激活漂移测量 80% 是执行噪声——**已发表工作的漂移数字可能同样被污染**（它们只报聚合指标）。
4. **记忆/程序边界与相变曲线**：16→256 样本的相变（0→0.375→0.938→1.000）给出"技能模块数据量"的第一手坐标。

## 五、补充检索（2026-10-01）：同类工作确认与定位修订

第二轮检索（海内外）确认：该方向 2026 年极度活跃，**未发现覆盖"门+锚+路由+技能+测量"五件套的单体项目，但每个组件都有更新或更成熟的方案**。新增必须引用/精读者：

| 工作 | 与本仓库关系 |
|---|---|
| **Engram Adapter**（EMNLP 2026 Findings, arXiv:2608.29327） | **高度同构**：同基座 Qwen3-4B，n-gram 匹配做选择性先验（≈本文词法路由）+ 标量门衰减；OOD 保持 99.4-100.1%。差异：他们门衰减后残差仍非零（~0.08% 范数），本文路由为结构性零执行；他们无真伪门 |
| **Memory as a Markov Matrix**（ICML 2026, arXiv:2605.04308） | **理论同构**：token-to-dictionary 映射、扩展状态空间保证旧转移不变（可证零遗忘）、样本复杂度界——与"新华字典理论"的字典机制同构的理论版 |
| **Brainstacks**（arXiv:2604.01152） | 覆盖本文跨层分支+零空间+路由组件且规模更大（Gemma-3-12B），并有随机初始化预训练实验（与本文走向实验同方向） |
| **PaST**（arXiv:2601.11258） | 对本文"知识/技能边界"发现的解法：SFT 与 RL 更新近正交 → 技能向量线性注入 |
| **Improving Sparse Memory Finetuning**（arXiv:2604.05248） | 消费级硬件 + 稀疏记忆改造 + KL 槽位选择（与本文锚定思路同源） |
| **DMoE**（arXiv:2606.14243）/ **JumpLoRA**（arXiv:2604.16171）/ **Zero-Leakage Routing**（arXiv:2604.14375）/ **Mechanistic CF Analysis**（arXiv:2601.18699） | 组件级相关：解耦专家注入 / JumpReLU 稀疏隔离 / 自主任务发现+路由 / 20 模型遗忘机制定位 |

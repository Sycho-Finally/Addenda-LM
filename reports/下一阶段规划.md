## 阶段 1：巩固证据（预计 1~2 周，全部可在 6GB 卡完成）

目标：把"单模型、单种子、玩具任务"三个最脆的短板补掉。

- E1 多种子：3 seeds × {16, 64, 128, 256} 相变四点 → 误差棒
- E2 第二基座：Qwen2.5-3B 或 Llama-3.2-3B 复跑走向测试 + 不遗忘实验 → "模型无关"实测
- E3 LoRA 对照：peft 库在同密码任务/同数据上实跑 → 与跨层分支正面对比
- E4 真实知识注入：门核证的真事实接入 mem/skill 实验 → 打通"真实数据全链路"
- E5 双技能干扰：两个技能模块并存（密码 + 倒序），测互扰与路由分流

退出标准：E1-E5 各出一份 JSON + README 结果表更新；结论表述全部带条件限定。

## 阶段 2：对齐文献（预计 2~4 周，以精读+复现为主）

- R1 精读并做笔记：Markov Matrix（理论对齐）、Engram Adapter（同基座机制对比）、Brainstacks（路由与零空间）、PaST（技能注入）、Sparse Memory Finetuning（KL 槽位）
- R2 把本文的门+证溯层与 Engram 式条件适配器嫁接：**他们的 gate 不做真伪核证——这是我们的可叠加增量**
- R3 PKM 形态实验：模块从稠密分支升级为 product-key 查找（对齐 Memory Layers 路线）
- R4 方法论短文：bf16 执行噪声三分解写成独立技术笔记（含复现脚本）

退出标准：R2 出对比实验（门+适配器 vs 裸适配器）；R3 出 PKM 版 vs 稠密版对比；R4 成稿。

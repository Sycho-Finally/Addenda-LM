### 阶段 1 实测结果（2026-10-02）

**E1 多种子相变曲线**（3 seeds，unseen exact / 逐位）：

| 训练样本 | seed 11 | seed 101 | seed 102 | 均值±std |
|---|---|---|---|---|
| 64 | 0.375 / 0.722 | 0.375 / 0.730 | 0.688 / 0.865 | 0.480±0.15 / 0.772±0.065 |
| 128 | 0.938 / 0.865 | 0.750 / 0.919 | 0.750 / 0.892 | 0.813±0.086 / 0.892±0.022 |

相变跨种子成立；n64 种子方差大（0.375-0.688），n128 稳定强势。单种子结论需带误差棒引用。

**E3 LoRA 基线**（r=16 q/v 全层，5.9M 参数，同 64 样本同 800 步）：

| | LoRA | 跨层加法分支 |
|---|---|---|
| seen | 1.000 | 1.000（n64 三种子 0.905-1.000） |
| unseen exact | 0.312 | 0.375 |
| unseen 逐位 | 0.703 | 0.722 |
| A 漂移（全局） | **+6.40，0/20 退化**（max +15.6 向上） | +2.419，6/20 退化 |

读法：LoRA 泛化与分支相当，旧任务无退化（漂移方向为正=格式锐化）；分支的结构优势不在学习质量，而在**路由 bit-exact 隔离与可摘除性**。LoRA 的 A 漂移含 bf16 执行噪声成分（on/off 上下文不同）。

**E5 双技能干扰**：A/B 两密钥模块并存，路由抽检 0 错误，A/B 任务各 1.000；全局足迹 A +5.39（7/20）、B +3.84（6/20）——参数隔离下互扰为零，全局激活足迹与单模块同量级。

**E2 跨模型验证**（2026-10-02 补）：
- E2a 跨厂商 SmolLM2-1.7B-Instruct：additive 注入 B 0→1.000，主干哈希不变，A 均值漂移 -0.196（SmolLM2 中文基线弱，逐条噪声相对更大：10/20 条 |d|>0.3，双向散布）——核心性质跨厂商成立，弱模型上逐条噪声更大。
- E2b 跨代 Qwen2.5-3B 路由：路由抽检 0 错误，**未路由输入 A 逐位为零在第二个模型上成立**；强制全局 -13.0（15/20）。
- 结论：「机制模型无关」在 Qwen3-4B / Qwen2.5-3B / SmolLM2-1.7B 三个模型上实测成立（跨代+跨厂商），限于 ≤4B 规模。

**E4 真实知识注入全链路**（门核证事实 → 跨层分支 → Qwen3-4B）：
- 5 条经门核证的 2026 真实事件（基座 cutoff 后，base 全部 0 命中）训练 800 步后：**生成完全一致 5/5 = 100%**。
- A 漂移（全局）+9.36（4/20，方向向上）；主干哈希不变。
- 读法：web → 门 → 注入 → 模型能答 的真实数据全链路打通；全局激活的足迹依旧需要路由兜底。

**E2（第二基座）/ E4（真实知识全链路）：✅ 已完成（2026-10-02）**。E4 全链路 + E2 跨模型已补齐。

## 阶段 2：对齐文献（预计 2~4 周，以精读+复现为主）

### 阶段 2 第一轮结果（2026-10-02）

**R3b PKM 粒度对照**：n_keys 32→128 / topk 8→16（参数 7.9M→~15M），结果与粗粒度完全一致（seen 1.000、unseen 0.000/逐位 0.108≈随机）——**粒度不是瓶颈，PKM 检索机制与数字结构不对齐是结构性的**。两配置负结果成立；结合 Markov Matrix 理论的解释：PKM 试图在既有状态的计算里做查表改造，而该任务的自然形态是"新状态扩展"或"稠密因子化"。稠密分支维持默认形态。

**R1 文献精读**：`lit_notes.md`（Markov Matrix 全文机制 + Engram 机制 + 生态位定位）。核心收获：Markov Matrix 的 ET（只调新 token 嵌入行，3072 参数）与我们的残差分支是**两种正交的模块形态**——前者=新状态扩展（零遗忘由构造保证，但只能触发基座既有能力），后者=既有状态转移重写（能存基座不知道的映射，但需要门/锚/路由）。他们的实验（FFT 学算符 token 把加法 100%→0%，ET 保持 100%）与我们的发现互相印证。

**新增提案 R5**：新 token ET 形态 vs 残差分支形态跑同一密码任务——预期 ET 失败（密钥不是基座既有能力，嵌入行无法路由到它），实证两种形态的能力边界。E2 跨厂商现象（A 漂移向上）与 Markov 论文的负遗忘现象同类，机理均未明——列为共同开放问题。

- R1 精读并做笔记：Markov Matrix（✅ 深读）、Engram Adapter（✅ 摘要+机制）、Brainstacks（⏳ 摘要级）、PaST（⏳ 摘要级）、Sparse Memory Finetuning（⏳ 摘要级）
- R2 把本文的门+证溯层与 Engram 式条件适配器嫁接：**他们的 gate 不做真伪核证——这是我们的可叠加增量**
- R3 PKM 形态实验：模块从稠密分支升级为 product-key 查找（对齐 Memory Layers 路线）
- R4 方法论短文：bf16 执行噪声三分解写成独立技术笔记（含复现脚本）

退出标准：R2 出对比实验（门+适配器 vs 裸适配器）；R3 出 PKM 版 vs 稠密版对比；R4 成稿。
